# Yerel A kanıtları

INDEX.json özgün kaynak byte/SHA256 ile taşınabilir çıktının byte/SHA256 değerlerini ayırır. external/tmp bir kaynak referansıdır; tam loglar burada saklanmaz. logs/ yalnız onaylı marker, test toplamı ve sınırlı hata bağlamını içerir. Gerçek kullanıcı/üretim kimlik bilgisi kabul edilmez.

FAIL kayıtları korunur. Native test PASS, wrapper FAIL sonucunu silmez. R yaşam döngüsü kapsamında eksik/pending türler başarı sayılmaz. Kısa doğal60 sonuçları resmî tam süre iddiası değildir. Kaynak kod hashleri kürasyon anındadır; geçmiş derleme hashleri olarak sunulmaz. Bu klasör tek başına yayın onayı değildir.
